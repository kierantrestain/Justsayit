# Contributing to Just Say It

Share bugs and ideas in [Just Say It Issues](https://github.com/kierantrestain/Justsayit/issues). For a bug, include the app and macOS versions, your Mac architecture, and steps to reproduce it. Review any text, recordings, or logs before sharing them.

For code changes, see the [build instructions](README.md#build-from-source). Keep changes focused, run the relevant tests, and explain what you verified. Source formatting uses SwiftFormat with `.swiftformat`. CI checks SwiftLint, runs the integration suite, and packages an Apple Silicon preview.

When suggesting dictionary entries, use the intended spelling with accents or punctuation where appropriate. Opt-in vocabulary suits names and phrases that may mean different things depending on context. Built-in entries should preserve the meaning of a transcript.
